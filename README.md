# DSNovel v7.0 — iOS 27 全局无感双源融合与人机交互重构版

## v7.0 核心重构亮点
1. **全局无感双源融合（仅封面上方标签标注来源 + 仅登录页分离操作）**：
   - 书架、书城（发现）、搜索、书籍详情与全屏播放器均已彻底移除冗余的书源筛选切换栏，两大书源（番茄畅听 + 喜马拉雅）在底层自动并发聚合、混排去重、并在播放受阻时自动后台无感切源。
   - 视觉上仅在**每本书籍封面上方展示高对比度来源标签（`番茄畅听` / `喜马拉雅`）**。
   - 操作上仅在 **“我的 -> 书源账号登录”** 区域保留喜马拉雅与番茄畅听的独立网页登录入口。
2. **全链路界面衔接与单层极简顶栏（HCI 深度优化）**：
   - 每个主界面顶部均精简为**单层液态玻璃控制栏**，视野更开阔、操作零层级负担。
   - **书架**：顶部内置“上次收听 · 一键续播”英雄卡片，并支持“我的书架 / 最近收听”切换与宫格/列表视图切换。
   - **书城**：单层 12 大精选频道导航 + 一键展开 4 列全部分类面板 + 今日热播横滑 + 3 列等高封面宫格。
   - **详情与播放器无缝衔接**：进入详情一次性并发加载全本章节并自动定位至上次收听所在的百集区间；底部悬浮迷你播放栏可一键展开全屏封面或直接打开章节目录。
